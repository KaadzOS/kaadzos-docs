## Skeleton, on purpose

The KaadzOS manual is authored in [`site/docs/`](https://github.com/KaadzOS/KaadzOS/tree/main/site/docs) in the main monorepo and published with the website at `/docs/`. This repository is the stable address for the handbook, not a second copy to keep in sync.

| Piece | Where it actually lives |
| --- | --- |
| Chapters | [`site/docs/index.html`](https://github.com/KaadzOS/KaadzOS/blob/main/site/docs/index.html) |
| Styles | [`site/docs/docs.css`](https://github.com/KaadzOS/KaadzOS/blob/main/site/docs/docs.css) |
| Search and scrollspy | [`site/docs/docs.js`](https://github.com/KaadzOS/KaadzOS/blob/main/site/docs/docs.js) |
| Vite page input | [`site/vite.config.js`](https://github.com/KaadzOS/KaadzOS/blob/main/site/vite.config.js) |

## The rule

Every chapter reads without JavaScript. Search, anchors, scrollspy and copy buttons are enhancements, not gatekeepers.
